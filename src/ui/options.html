📋 Rules

Rules change settings for tabs whose address matches. Use * as a wildcard; a pattern without https:// matches any scheme. The number beside each rule is its priority: when two rules disagree the higher one wins. The switch parks a rule without deleting it.

🗂️ Site groups

A group is a named list of address patterns. Point a rule at @name and it applies to every site in the group, so one rule can cover all your news sites.

Site access is off, so favicons cannot be coloured.

💾 Backup

Every setting and every rule, as one JSON document, plus the all-time count of tabs killed. Copy or download it to keep, and paste or choose a file to restore. Loading replaces all current settings and rules; the count only ever goes up.

📋 Rules

Rules change settings for tabs whose address matches. Use * as a wildcard; a pattern without https:// matches any scheme. Higher priority wins, 0 disables a rule.

🗂️ Site groups

A group is a named list of address patterns. Point a rule at @name and it applies to every site in the group, so one rule can cover all your news sites.

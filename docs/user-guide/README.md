# 📖 User guide

How Timed Tabs behaves and how to make it behave differently. No account, no server,
nothing to set up beyond installing it.

- [features.md](features.md) — the full tour, with screenshots: the timer, what
  happens at zero, the five indicators, the popup, the Tabs page, rules, site groups
  and settings.
- [feature-flags.md](feature-flags.md) — the parts still behind a switch, how to turn
  them on, and what each one does.
- [privacy.md](privacy.md) — what is stored, where, how long it is kept, and what to
  do about private windows. The formal version is the
  [privacy policy](../../PRIVACY.md).

New here? Start with [features.md](features.md) and read it in order; it follows the
extension from the timer outwards.
